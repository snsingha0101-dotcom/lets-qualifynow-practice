Question 1 / प्रश्न 1
If CAT is coded as DBU, then how will DOG be coded in the same way? यदि CAT को DBU के रूप में code किया जाता है, तो उसी तरीके से DOG को कैसे code किया जाएगा?
(A) ENH
(B) EPH
(C) FPH
(D) EOG
Answer: (B) EPH उत्तर: (B) EPH
Each letter is moved one step forward: D→E, O→P, G→H. Therefore DOG → EPH. प्रत्येक letter को एक step आगे बढ़ाया गया है: D→E, O→P, G→H. इसलिए DOG → EPH।

Question 44 / प्रश्न 44
If the letters in odd positions are reversed among themselves and the letters in even positions are reversed among themselves, how will ABCDE be coded? यदि odd positions के letters को आपस में reverse किया जाए और even positions के letters को भी आपस में reverse किया जाए, तो ABCDE को कैसे code किया जाएगा?
(A) EBCDA
(B) EADCB
(C) CBAED
(D) EDCBA
Answer: (A) EBCDA उत्तर: (A) EBCDA
Odd-position letters are A, C, E. Reversing them gives E, C, A. Even-position letters are B, D. Reversing them gives D, B. Placing them back in their original positions: Position 1 = E Position 2 = B Position 3 = C Position 4 = D Position 5 = A Therefore ABCDE → EBCDA. Odd-position letters A, C, E हैं। इन्हें reverse करने पर E, C, A मिलता है। Even-position letters B, D हैं। इन्हें reverse करने पर D, B मिलता है। अब इन्हें उनकी original positions पर रखने पर: Position 1 = E Position 2 = B Position 3 = C Position 4 = D Position 5 = A इसलिए ABCDE → EBCDA।

📌 Practice Strategy / अभ्यास रणनीति

In Coding-Decoding questions, first identify whether the coding is based on letter shifting, opposite alphabet, alphabetical position, rearrangement, word relation or artificial language.

Coding-Decoding questions में पहले यह identify करें कि coding किस rule पर आधारित है — letter shifting, opposite alphabet, alphabetical position, rearrangement, word relation या artificial language.

Exam Tip: Instead of guessing the rule by looking at the answer, first establish the exact relation from the given examples.

परीक्षा टिप: Answer देखकर rule guess करने के बजाय दिए गए examples से पहले exact relation establish करें।
