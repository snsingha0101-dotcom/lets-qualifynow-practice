Q25

Find the related letters / संबंधित अक्षर ज्ञात कीजिए

English: ABC : BCD :: PQR : ? हिंदी: ABC : BCD :: PQR : ?
A) PQR
B) QRS
C) RST
D) QRT
Answer / उत्तर: (B) QRS

English: Every letter moves one position forward: A→B, B→C, C→D. Therefore P→Q, Q→R, R→S = QRS.

हिंदी: प्रत्येक अक्षर एक position आगे जाता है: A→B, B→C, C→D। इसलिए P→Q, Q→R, R→S = QRS।
